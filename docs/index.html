Arc Favorites+

Arc caps pinned favorites at 12. This adds unlimited favorites, searchable and reorderable from your menu bar, opening straight back into Arc.

1 Install the menu bar app

brew tap alpha-neutr0n/arcfavoritesplus
brew install --cask arcfavoritesplus

Installs via Homebrew, not a downloaded .dmg — no Gatekeeper warning, no admin password prompt. The ★ icon appears in your menu bar within a few seconds and starts automatically at login from then on.

2 Install the browser extension

Add to Arc (Chrome Web Store)

Works in Arc directly — Arc reads from the same Chrome Web Store.

3 Pair the two

Click the ★ icon in your menu bar → Copy Pairing Token. Then right-click the Arc Favorites+ extension icon → Options → paste the token → Save.

4 Start adding favorites

Right-click any page in Arc → Add to Arc Favorites+. Open, search, rename, reorder, and remove favorites from the ★ menu at any time.

Free vs. unlocked

Free tier: up to 5 favorites, no account needed. Beyond that, unlock unlimited favorites with a one-time purchase — no subscription.
